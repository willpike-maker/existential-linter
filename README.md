Traditional linters harass you about PEP 8 compliance, missing type annotations, and 80-character line lengths. **existential-linter** cuts through the superficial trivia to analyze the cosmic futility, hubris, and creeping existential despair embedded in your architecture.

---

### 🕳️ Core Architectural Features

- **Hubris Detection**: Flags identifiers like `success`, `perfect`, `final`, or `fix` and suggests sobering alternatives (e.g. `temporary_respite_before_entropy`).
- **Nihilistic Boolean Analysis**: Evaluates hardcoded `True` literals as unfounded optimism in an uncertain universe.
- **Mortal Optimism Warnings**: Intercepts `try / except` blocks as touching yet futile attempts to impose order on entropy.
- **Docstring Futility Profiling**: Flags `TODO` comments as delusions of tomorrow that will inevitably outlive your organization.

---

### 🚀 Installation & Usage

```bash
# Clone the monument to futility
git clone https://github.com/willpike-maker/existential-linter.git
cd existential-linter

# Analyze your codebase against the void
python3 existential_linter.py sample_target.py
```
